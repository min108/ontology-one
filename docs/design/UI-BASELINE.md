# 知元界面基准 v1

写给实施者。本文件是界面的中间层规范：蓝图第十部分定原则，本文件定数值和结构，`benchmarks/` 下的基准页定长相。三者不一致时，以基准页为准，其次是本文件。没有画出的页面，按本文件和 06 状态板推出，不自创版式。

配套文件：

| 文件 | 作用 |
|---|---|
| `tokens-v2.css` | 完整令牌表。实施时替换 `frontend/src/design/tokens.css` |
| `benchmarks/01`–`06` | 六张高保真基准页，1440×900 为设计基准。左下角的深色小面板是基准页自己的状态切换器，不是产品界面 |
| `benchmarks/assets/base.css` | 基准页共用样式。类名与平台组件一一对应（§9），数值全部来自令牌，可直接抄进 CSS Modules |
| `benchmarks/check-baseline.js` | 自检脚本。§11 的验收口径就是它的口径 |
| `legacy-bridge.css` | 旧页面过渡补丁草案（§10） |

本基准与蓝图 §10.2、§10.3 不一致的地方（强调色、字号阶梯、默认视图、身份条、面包屑、二级导航、页面级页签）是规划方已裁决的方向，见 `docs/blueprint/rounds/R3-PLAN.md` 第 2 节；实施时在 ADR 中登记，蓝图原文不改。

> 规划方审阅补充（2026-11-17）：① 只读、跨机构查看等**限制状态**除写在机构选择器浮层里，还要在顶栏机构选择器旁以状态标签常显，不能只藏在浮层里；② 04 中的“稍后”需要服务端有对应状态，R3 不提供；③ §5.3 一级动作的“撤销”只在现有决定接口能把条目设回待处理时提供，否则不显示撤销；④ §6.5 数字来源浮层在 R3 只做组件与画廊示例，业务数字的五项来源随后续轮次接入。

## 1 三种页面形态

每张页面先归入一种形态，再套对应的骨架。蓝图 §10.6 的五种原型并入这三种；画布页和对话页沿用本文件的外壳、标题区和组件，版式各自另出基准。

| 形态 | 回答的问题 | 放什么 | 不放什么 | 对应页面 | 基准页 |
|---|---|---|---|---|---|
| **工作台** | 现在该做什么 | 一件焦点（36 号的一句结论加主按钮）；最多三块摘要，每块写明数目和最要紧的两项；常用入口 | 完整明细；统计口径说明；数值为 0 的区块；口号和插图 | 工作台；各工作区今后的首页 | 01 |
| **列表页** | 有哪些，哪些要我处理 | 一句结论；工具条（筛选、搜索）；表格不超过 6 列；分页 | 说明段落；卡片堆叠的列表；行内 3 个以上按钮 | 本体目录、我的报告、账号与权限、素材、审计 | 02 |
| **对象页** | 这是什么，把这件事做完 | 当前对象的结论和主要操作；其余按任务顺序收进折叠行和抽屉 | 与当前对象无关的指标；表单式的首屏 | 见下 | 03、04、05 |

对象页有三种版式：

- **档案页**（03）：主栏加右栏。主栏首屏是业务语言卡，下面是折叠行；右栏写怎么用、下一步。用于要素页、报告详情、机构主页。
- **列表加详情**（05）：左栏收件箱，右栏当前一项，动作固定在右栏底部。用于审核中心、反馈事项。
- **三栏工作台**（04）：左栏条目，中栏当前条目，右栏依据。用于建设方案核对、台账接入、素材详情。

三种形态共用同一个外壳和同一种标题区。

## 2 页面骨架

所有页面由 `AppShell` 和 `PageHeader` 给出骨架。**功能目录里不写页面容器、页边距、最大宽度**；页面组件只产出标题区的内容和内容区的块。

### 2.1 外壳

| 部位 | 数值 | 规则 |
|---|---|---|
| 顶栏 | 高 56，白底，下边 1px | 自左至右：标志与“知元”（占导航的宽度）· 机构选择器 · 万能入口（最宽 440）· 任务 · 通知 · 帮助 · 助手 · 用户菜单。机构选择器的文字落在正文左边线上 |
| 机构选择器 | 浮层宽 320 | 机构、身份、查看范围都在这里。原身份条取消。只读、仅审核等身份限制写在浮层里，不再占一条横幅 |
| 左侧导航 | 展开 216，收起 72 | 展开：六个工作区，当前工作区在原位展开二级，项高 36。收起：图标加 12 号文字，项高 56，指到工作区时二级列表从右侧浮出。二级页签横条取消。新旧页面的入口在同一列表里，不做区分 |
| 当前位置 | 3px 指示条 | 当前项浅灰底、粗体，左侧一条强调色指示条。全屏只此一处 |
| 助手停靠栏 | 宽 420 | 视口 ≥ 1680：停靠在右侧，挤压正文。视口 < 1680：盖在正文之上（大阴影，不加遮罩，不改变正文布局），Esc 或再点“助手”收起 |
| 用户菜单 | — | 视图切换（简洁 / 专业）、账号安全、退出 |

### 2.2 一条左边线

正文左边线 x = 导航宽 + 页边距。页边距：视口 < 1440 为 24，≥ 1440 为 32。标题、结论、工具条、表格、卡片的左边都落在这条线上，不居中，不各自缩进。

| 视口 | 导航 | 左边线 x | 正文宽 | 说明 |
|---|---|---|---|---|
| 1366×768 | 展开 216 | 240 | 1102 | 工作台、列表页、档案页 |
| 1366×768 | 自动收起 72 | 96 | 1246 | 三栏页、列表加详情页：视口 < 1440 时自动收起导航 |
| 1440×900 | 展开 216 | 248 | 1160 | 设计基准 |
| 1920×1080 | 展开 216 | 248 | 上限 1440 | 正文靠左，右侧留白；助手停靠时正文宽 1220 |

内容最大宽：工作台、列表页、分栏页 1440（`--zy-content-max`）；档案页和表单页 1120（`--zy-reading-width`）。超出部分留在右侧，不拉伸表格，不居中。三栏页在视口 < 1280 时右栏收为抽屉。宽度 < 1024 的只读简化布局不在本基准内，沿用蓝图 §10.11。

### 2.3 标题区

内容区之上只有两条：顶栏和标题区。面包屑、身份条、页签、说明句都不再单独占一条。

```
[‹ 上一级名称]                                   ← 只有对象页有；12 号；高 18，下距 4
标题（20/700）[状态标签]            [说明] [次要] [主要]   ← 行高 36；右侧动作区
一句结论（14，次要色；要紧的数加粗为墨色）        ← 上距 4；工作台改为 36 号结论
```

| 项 | 数值与规则 |
|---|---|
| 上内边距 | 24 |
| 下内边距 | 16（到内容区第一块） |
| 标题 | 20 / 28，700；不超过 12 个字；过长截断 |
| 状态 | 紧跟标题右侧的状态标签，最多 2 个 |
| 返回路径 | 只在对象页出现，写上一级的名称（“‹ 本体目录”），放在标题上方，不写完整面包屑 |
| 结论 | 每页一句，写结果不写说明：“共 128 项，5 项待审核”，而不是“按业务含义查找数据项、规则……”。档案页的结论由首屏卡片的一句话承担，标题区不重复 |
| 动作区 | 右对齐，高 36，间距 8。自右向左：唯一主按钮 · 至多一个次要按钮 · “其他操作”图标按钮。主按钮不可用时，在它左侧用一句话写明原因 |

三种变体的高度（内容区起点 y）：列表页 102（158）；对象页无结论 98（154）、有结论 124（180）；工作台 192（248）。

**主按钮放在哪**：整页的主要动作永远在标题区右侧。分栏页里针对“当前选中这一条”的动作，放在详情栏底部的固定动作条（04 的“采纳 / 改一改”，05 的“通过并发布 / 退回”）。一屏只有一个实心按钮：标题区已有主按钮时，动作条里只用次要和文字按钮（04）；标题区没有主按钮时，动作条里可以有一个（05）。

### 2.4 页签、工具条、内容区

- **页签**：不做页面级页签。同一批数据的分类用工具条里的分段选择（不超过 5 项，带数目）。对象页的分区优先用折叠行；确有两块以上各自成表的重内容时，才在内容区里用页签，样式为墨色文字加墨色下划线。
- **工具条**：高 36，紧接标题区。筛选在左（一个分段选择加至多两个下拉），搜索在右（宽 280）。工具条里不放主按钮。专业视图在搜索左侧多出“列设置”。
- **内容区**：块与块纵向间距只用 8、16、32（§4.3）。卡片不套卡片：卡片里需要分组时用 12 号小标题、分隔线或折叠行。
- **分栏页**：占满视口高度，各栏自己滚动，页面不滚动。左栏宽 320，三栏页右栏宽 320，栏间距 16。

## 3 分层呈现

信息分四层放。一条信息放在哪一层，按任务顺序定：先要决定的在首屏，决定之后才用得到的收起。同类信息收在同样的位置。

| 层 | 放什么 | 怎样打开 | 上下文 |
|---|---|---|---|
| 首屏 | 当前任务、必要状态、主要操作 | 进入页面即见 | 不滚动就能决定下一步 |
| 就地展开 | 同一对象的更多内容：全部条目、适用条件、版本、动态 | 折叠行、摘要块底部的“其余 N 项” | 在原位展开，不推走主要操作 |
| 抽屉 | 另一类信息，看完要回来：原文出处、依据、数字来源、技术详情 | 从右侧滑出，宽 480 或 640 | 主区保留并变暗；一次只开一个 |
| 关联跳转 | 另一个对象或另一个工作区的页面 | 链接、下一步条 | 对象页带返回路径；回来时恢复筛选、选中项和已展开的层 |

**一条信息放哪一层，依次问：**

1. 不看它，就无法决定下一步吗？是 → 首屏。
2. 它是结论的直接依据，而且一句话说得完吗？是 → 首屏，紧跟结论（04 的“需要你确认”）。
3. 它是同一对象的更多内容，决定之后才用得到吗？是 → 折叠行。
4. 它是另一类信息，看完还要回到这里吗？是 → 抽屉。
5. 它属于另一个对象吗？是 → 关联跳转。
6. 它是编号、内部字段、原始数据吗？是 → “技术详情”，只在专业视图出现（§6.3）。

**首屏字符预算**（1440×900，统计内容区的文字字符，顶栏和导航不计）。参考基准在 13 号正文下是 800 字符；知元正文 14 号、行距更松，按形态分别定：

| 形态 | 简洁视图上限 | 专业视图上限 | 基准页实际 |
|---|---|---|---|
| 工作台 | 400 | — | 295 |
| 档案页 | 500 | 600 | 280 / 330 |
| 分栏页（三栏、列表加详情） | 650 | 750 | 394–521 / 440–605 |
| 列表页（含表格行） | 800 | 900 | 694 / 741 |

工作台和档案页另有占比要求：全部层级不少于 600 字符时，首屏不超过全部层级的一半（03 为 38%）。

**其他硬规则**：收起的地方写明里面有什么、有多少（“其余 2 份，都已发布”“动态　5 条，最近一次是审核通过”），不写“更多”“详情”；同一信息一屏只出现一次（机构名只在顶栏，标题区结论与卡片不重复）；不用灰色句子解释统计口径或系统机制，确需解释的进悬浮提示。

## 4 字、色、距

### 4.1 字号五级

| 令牌 | 字号 / 行高 | 字重 | 用途 |
|---|---|---|---|
| `--zy-font-display` | 36 / 44 | 700 | 首屏结论（工作台）、关键数字。一屏最多一处 |
| `--zy-font-heading` | 20 / 28 | 700 | 页面标题。对象的一句话也用 20，字重 400 |
| `--zy-font-title` | 16 / 24 | 700 | 卡片标题、区块标题、对话框标题 |
| `--zy-font-body` | 14 / 22 | 400 | 正文、表格、表单；按钮与表头用 500 |
| `--zy-font-caption` | 12 / 18 | 400 | 次要：标签、时间、小标题、标注。不用于需要读的句子 |

- 全站只有这五级。任何文字不小于 12；正文、表格、表单不小于 14。不用相差 1px 的字号区分层级。一张页面通常只出现四级（36 只属于工作台）。
- 字重 400 / 500 / 700。强调靠 700，不靠颜色。500 需要补一份同字符集的 Noto Sans SC 500 字重文件；补齐前浏览器回落为 400，基准页就是这个状态，所以设计上不依赖 500 区分层级。
- 字体只用黑体。衬线只留给报告封面和领导导览。等宽只在“技术详情”里用。数字用等宽数字（`tabular-nums`）。

### 4.2 颜色

中性色承担全部结构：冷白底 `#F1F3F6`，卡片白面，正文墨色 `#12161B`，次要文字 `#5B6572`，分隔线 `#DDE2E9`。

**强调色只有品牌红 `#A51C30`**（白字对比 7.48:1；悬停 `#8A1728`）。它只做四件事：

1. **主要动作**：实心主按钮。
2. **需要你决定**：需要确认的提示条（浅红底加红色图标）。
3. **当前位置**：导航当前项的指示条；主线步骤里的当前步。
4. **键盘焦点**：2px 焦点环，外扩 2px。

**一屏不超过三处**（品牌标志和焦点环不计）。链接是墨色加下划线；页签、分段选择、选中行、复选框、单选、开关、分页当前页都用墨色或浅灰底，不染强调色。原靛青交互色和紫色智能色取消，旧名保留为过渡别名并指向中性色（见令牌表）。

状态色（成功、提醒、错误、提示）只用于状态标签和状态图标，必须同时带图标和文字，面积限于标签和 16px 图标。原文高亮用淡黄底 `--zy-mark-bg`，不用强调色。种类色只用于图谱和图表；页面里的种类标签是中性色加图标。危险操作不用红色区分，见 §5.3。

### 4.3 间距、圆角、阴影

- **纵向间距三档**：8（同组内的行与行）、16（卡片与卡片、组与组）、32（区块与区块）。对应 `--zy-gap-tight`、`--zy-gap`、`--zy-gap-section`。组件内部的尺寸（标题区上距 24、卡片内边距 24、业务语言卡内边距 32、折叠行高 48）由组件定义，页面不改。
- **圆角**：标签 4，控件 6，卡片 10，对话框 14。不用更大的圆角。
- **阴影**：卡片是 1px 细边，无阴影。阴影只给浮起的东西：下拉与浮层用中阴影，抽屉、对话框、覆盖态的助手栏用大阴影。
- 不用渐变、半透明、毛玻璃。

## 5 按钮、表格、确认

### 5.1 按钮三级

| 级别 | 外观 | 用在哪 |
|---|---|---|
| 主要 | 实心强调色，白字 | 一个区域只有一个，一屏只有一个。整页主要动作在标题区右侧 |
| 次要 | 白底，1px 灰边，悬停时边变墨色 | 同区域的其他动作 |
| 文字 | 无边无底，悬停浅灰底 | 取消、稍后、表格行内操作、跳转 |

高 36，圆角 6，字重 500；表格行内用高 28 的文字按钮。按钮文字是“动词加对象”，不超过 8 个字。五种状态（默认、悬停、聚焦、禁用、进行中）见 06 第 5 节。禁用是浅灰底，文字仍可读；旁边必须有一句原因。进行中显示转圈并把文字换成“提交中”。

### 5.2 表格

表头高 44，行高 48（专业视图可选 40）。默认不超过 6 列，含操作列。列宽档位：标签列 128，时间与操作列 168，短文字列 96，次要长文字 28%，名称列占剩余宽度。名称是进入详情的链接。**一行最多 2 个文字按钮**，其余收进“更多”下拉。分页在表格卡片底部：左侧“第 1–15 项，共 128 项”，右侧页码。每页条数沿用各页现有实现。空结果时表头和分页都不出现，只留状态块。

### 5.3 确认级别

危险与否不靠颜色，靠确认的重量（06 第 10 节）：

| 级别 | 适用 | 形式 |
|---|---|---|
| 一级 | 能撤销：采纳、不要、稍后、保存 | 不问，直接做；轻提示里给 8 秒“撤销” |
| 二级 | 影响别人或对外生效：提交审核、通过并发布、退回 | 对话框（宽 480）。标题是动词短语；正文两三条写清会发生什么、能否撤回；主按钮重复动作名 |
| 三级 | 不能撤回或范围大：归档、撤回发布、清理演示资料 | 对话框列出影响，勾选“我已了解”后按钮才可用；按钮是次要样式 |

## 6 状态、标识、细节

### 6.1 四种状态

全部用 `StateBlock`，左对齐，不放插图：一个 32px 图标、一句 16 号标题、一句 14 号说明、一个动作（06 第 9 节）。

| 状态 | 写什么 | 例 |
|---|---|---|
| 空 | 一句话加一个起点动作 | “还没有报告。在应用助手完成一次回答，就能生成报告。”〔去应用助手〕 |
| 加载 | 300 毫秒内不显示；之后是与内容同形的骨架；超过 3 秒写明到了哪一步 | “正在定位原文，第 3 步，共 4 步” |
| 出错 | 先说保住了什么，再给继续的办法；不出现状态码和英文报错 | “这次整理中断了。已完成的 9 条已保存，剩下 3 条可以继续。”〔继续整理〕 |
| 无权限 | 需要什么身份、找谁、现在能做什么 | “你看不了草稿。查看草稿需要建设或审核身份，可以找本机构管理员林海开通。”〔返回目录〕 |

**数值为 0 的区块整体不出现**，不显示“0”和“暂无”。整页都空时，标题区的结论换成起点（01 空数据状态：“先交一份制度”加主按钮）。

### 6.2 状态、种类、来源标识

- 状态标签：高 24，圆角 4，12 号，图标加文字。取色：已发布、高把握为成功；待审核、待核对、需核对为提醒；已退回为错误；整理中为提示；草稿、已归档、存疑为中性。名称只取词表。
- 种类：标题区和卡片里用带框的中性标签加种类图标；表格和列表里用图标加文字，不带框。
- **AI 内容**：星形图标加文字，“AI 整理 · 待人工核对”“AI 整理 · 已人工审核”“AI 建议”，白底细边。不用专门的颜色。
- **演示与模拟**：“模拟演示 · 未调用真实模型”“演示数据”用提醒色标签；本地规则识别的条目标“本地规则识别 · 未经智能整理”。这些标识跟着内容走，报告和导出里同样带上。模拟结果的页面不得出现“真实模型回答”标识。

### 6.3 技术详情

编号、内部字段名、原文字符定位、原始数据（JSON）一律不在简洁视图出现。专业视图里收在对象页最后一条折叠行“技术详情　编号、原文定位、原始数据”，默认收起；列表页不为它们设列（可经“列设置”加）。审计这类以技术记录为主的页面：表格只列时间、谁、做了什么、结果四列，点一行在 640 抽屉里看技术详情。

### 6.4 日期与时间

北京时间，`YYYY-MM-DD HH:mm`，24 小时制，不写秒；只有日期时写 `YYYY-MM-DD`。工作台和收件箱里当天、昨天写“今天 09:58”“昨天 17:20”。日期输入一律用组件库的日期控件（中文占位“选择日期”，中文星期和月份），不用浏览器原生日期框。

### 6.5 数字来源

报告、工作台、助手回答里的业务数字带虚下划线，点开是来源浮层：来源、时点、口径、版本、负责人五项（06 第 8 节）。五项不全的数字不显示成可点。

## 8 下一步条

主线五步：交进来 → 看一眼 → 点通过 → 问一个问题 → 出一份报告。

- **工作台**用完整的一行步骤（01）：已完成是墨色勾，当前步是强调色数字加粗体名称，未到是灰圈。右端写最近一次的时间。
- **主线上的页面**在内容区底部放下一步条（04、05；高 56，白底卡片）：左侧是迷你步骤（只有当前步带名称），中间一句“下一步：……”，右侧至多一个按钮。普通页面里它吸在视口底部；分栏页里它是最后一行。
- 下一步条在内容区之内，不算内容区之上的横条。
- 按钮规则（06 第 11 节）：本页的事还没做完，不放按钮（主按钮在标题区）；这一步要等别人，写明等谁，给一个文字按钮；本页的事做完了、标题区已没有主按钮，下一步条的按钮升为主要按钮。任何时候一屏只有一个实心按钮。
- 不在主线上的页面（从目录直接打开的要素页）不显示下一步条，“下一步”写在右栏。

## 10 旧页面过渡

26 个二级入口里的 15 个旧页面，在重建之前先套一段作用于 `.legacy-root` 的样式补丁（`legacy-bridge.css`），并统一放进新的外壳和标题区。目标是同屏时不再是两套视觉语言，不是把旧页面做成新页面。

**拉齐这些：**

| 项 | 做法 |
|---|---|
| 字体与标题 | 衬线标题改黑体；h1 20 / 700，h2 16 / 700，h3 14 / 700；去掉字距 |
| 页面容器 | `.page` 的内边距和最大宽度改成与新页面相同，靠左不居中，标题左边落在同一条左边线上 |
| 强调色 | 主按钮沿用品牌红（旧朱红与新强调色同值）；页签选中、品牌红标签、紫色标签退为墨色或中性；危险按钮退为次要样式 |
| 圆角 | 卡片 16 → 10，按钮与输入 8 → 6，对话框 18 → 14 |
| 最小字号 | 表格、表单、按钮、提示统一 14；标签、辅助文字统一 12。页面专属类靠构建期字号钳制兜底（做法写在补丁文件头） |
| 渐变与半透明 | 去掉背景渐变、毛玻璃、半透明卡片和彩色阴影：白面，1px 细边 |
| 重复的横条 | 旧页面自带的英文小字眉题和面包屑隐藏，由外壳给出当前位置 |

**不动这些：** 页面内部的栅格和分栏；表格的列与内容；表单字段和校验；业务逻辑、请求、路由；旧组件的结构；页面里的文案（文案编辑随各页重建进行，不在补丁里做）。补丁不新增类名，不改旧页面的源文件。

旧页面套补丁后同样要过 §11 的 A1、A2、B1、C1 四条。

## 11 可自动检查的验收条件

用浏览器自动化在 1366×768、1440×900、1920×1080 三个视口打开每张页面的每个状态，读计算样式与元素位置。`benchmarks/check-baseline.js` 是这套口径在基准页上的实现；实现后的页面按同一口径写进 e2e。为了能测，`PageHeader` 的标题、内容区根节点、表格首行各带一个稳定的测试标识。不做像素叠图比对。

| 编号 | 条件 | 怎么测 |
|---|---|---|
| A1 | 没有小于 12px 的文字 | 遍历可见文字节点，取父元素计算字号的最小值 |
| A2 | 小于 14px 的文字只出现在次要类里 | 同上；字号小于 14 的节点，其祖先必须是标签、时间、小标题、标注这几类组件（清单见脚本 `SMALL_OK`） |
| A3 | 一张页面的字号不超过 5 种，且都在 12 / 14 / 16 / 20 / 36 之内 | 收集可见文字的计算字号去重 |
| B1 | 所有页面标题的左边线 x = 导航宽 + 页边距；内容区第一块与标题同一个 x | 读标题与内容区首块的 `getBoundingClientRect().left`。同一视口、同一导航状态下，全站只有一个值（1440 下为 248） |
| B2 | 内容区之上只有顶栏和标题区。1366×768 下内容区起点 y ≤ 196（工作台 ≤ 256） | 读内容区根节点的 top；并断言顶栏与内容区之间只有一个标题区节点 |
| B3 | 1366×768 下，列表页第一行数据的 y ≤ 264 | 读表格首个数据行的 top（基准页为 255） |
| C1 | 三个视口下没有横向滚动，内容不被截断 | `scrollWidth ≤ clientWidth`（页面与内容区） |
| D1 | 首屏字符不超过 §3 的预算 | 1440×900 下，统计内容区内与视口相交的可见文字字符数 |
| D2 | 工作台与档案页，全部层级 ≥ 600 字符时首屏占比 ≤ 50% | 全部层级 = 可见文字 + 收起的折叠行 + 抽屉里的文字 |
| E1 | 一屏内强调色不超过 3 处 | 统计视口内背景色等于强调色的元素、带强调色指示条的元素和“需要你确认”提示条；标志与焦点环不计 |
| E2 | 一屏只有一个主要按钮 | 统计视口内可见且未禁用的主要按钮 ≤ 1 |
| F1 | 样式里没有颜色、字号、尺寸的裸值；没有外部 URL | 对 CSS Modules 与页面源文件做文本检查（现有令牌检查脚本加上 px 与外链两条） |
| G1 | 表格不超过 6 列（简洁视图）；每行可见的行内按钮 ≤ 2 | 数表头单元格与首行操作列里的按钮 |
| G2 | 状态标签都有图标和文字 | 每个状态标签内同时有图标元素和非空文字 |
| G3 | 简洁视图里不出现编号、内部字段名、JSON | 对可见文字做正则：`[A-Z]{2,}-\d+`、32 位十六进制、`{"`、下划线连接的英文标识 |
| G4 | 空数据时没有显示“0”的指标块 | 用空数据夹具打开工作台，断言没有内容为 0 的数字块，且有一个主要按钮 |
| G5 | 日期显示符合格式；没有原生日期框 | 正则检查可见日期文字；断言没有 `input[type=date]` |
