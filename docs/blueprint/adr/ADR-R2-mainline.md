# ADR-R2：复用既有流程完成汇报主线

- 日期：2026-11-16；状态：实施中；适用版本：1.1.0。
- 配方 A 复用旧分段、候选提炼和采纳事务；迁移0002仅新增三表。提炼失败按原文条款兜底，标识本地识别并限制为“存疑”。引文定位失败不得采纳。采纳与旧提交动作在同一机构事务中执行，重复应用不重复建要素。
- 审核中心复用原要素动作。R2提案的提交人、最后编辑人由服务端保存，旧编辑和还原也不能擦除；旧动作同样执行职责分离。既有未经过提案的旧页面行为保留，新中心对历史记录按提交与编辑活动核对职责，并检查原文。
- 报告仅从本人已完成的服务端会话读取；不接受客户端回答或报告规格。基础版支持有原文锚点的制度回答、段落及表格。数值用引用原文核对，容许0.5%舍入差，未对应即阻断。完整查询结果句柄、语义复核角色和自由编辑在R7补齐。
- 迁移0003新增成果、版本和访问日志。只保存实际展示的规格、引用和表格，不保存会话、工具行全集或密钥。HTML/Word由规格确定性生成，两格式通过后才提交；文件元数据记录大小与哈希，下载重现并核对，升级造成不一致时要求再次生成。所有成果默认本人私有；查看和下载审计是只读能力中唯一允许的附带写入。
- 环境变量模型配置优先于既有机构配置。环境密钥不落盘；配置页不允许把它保存回文件，连接测试的验证标记仅保留在内存。
- S0把浏览器、断网与升级演练放入手动完整层，保留快速层及一份汇总构件。首次快速CI暴露规划提交改动冻结用例清单导致哈希不符；恢复为R1验收清单原字节，既有SDK补登记规则不变，没有移除用例或断言。

- GitHub连接器没有dispatch能力，CLI返回Forbidden，网页工具不可用；按守则D2增加显式`[R2-FULL]`代码提交标记作为人工触发后备，仅对`dev/r2-sprint`生效，仍保留workflow_dispatch。普通推送只跑快速层，完整层最多两次。该调整不改变仓库访问权限或验收断言。
