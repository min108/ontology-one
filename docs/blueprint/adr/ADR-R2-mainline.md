# ADR-R2：复用既有流程完成汇报主线

## R2.1 更正（2026-11-17，以下优先于历史决定）

- 按独立验收修复八项；不新增迁移、版本、权限或功能包。候选编辑仅传三项业务字段，失败后重读，刷新保留内容；最后编辑人只由实际修改更新，后续采纳不能覆盖。
- 报告按每段和每行明确引用核验，原文与单位共同支持数值；量级归一、计数精确，金额才有 0.5% 容差。按负责人 R2.1 明确规格，裸数字、序号、年份和日期不再纳入此数字门，替换对应旧测试预期并新增单位、量级和跨行反例；未删除用例。XML 非法控制字符在 Word 渲染前剔除。
- 被数字或引用门拦下时，一键追问绑定服务端原回答及原参考范围，完成后自动生成一次；不改变授权或核验。发送失败可重试，后续报告重试继续使用新回答。
- 环境覆盖默认关闭；演示显式开关与 Compose 模型覆盖文件共同传入 api/agent/worker，迁移和非 Harness 子进程不接收提供方变量。来源标注从实际配置判定，外部标记仅能降为模拟。
- R2.1 完整 CI 只运行一次；三次真实模型均使用浏览器主线，直接核对修改正文、审核状态、报告数字和 python-docx 可读的标题与表格。保留手选制度：自动模式只预选技能和数据源，不能保证优先检索刚发布的制度。

- 日期：2026-11-16；状态：已实施；适用版本：1.1.0。
- 配方 A 复用旧分段、候选提炼和采纳事务；迁移0002仅新增三表。提炼失败按原文条款兜底，标识本地识别并限制为“存疑”。引文定位失败不得采纳。采纳与旧提交动作在同一机构事务中执行，重复应用不重复建要素。
- 审核中心复用原要素动作。R2提案的提交人、最后编辑人由服务端保存，旧编辑和还原也不能擦除；旧动作同样执行职责分离。既有未经过提案的旧页面行为保留，新中心对历史记录按提交与编辑活动核对职责，并检查原文。
- 报告仅从本人已完成的服务端会话读取；不接受客户端回答或报告规格。基础版支持有原文锚点的制度回答、段落及表格。数值用引用原文核对，容许0.5%舍入差，未对应即阻断。完整查询结果句柄、语义复核角色和自由编辑在R7补齐。
- 迁移0003新增成果、版本和访问日志。只保存实际展示的规格、引用和表格，不保存会话、工具行全集或密钥。HTML/Word由规格确定性生成，两格式通过后才提交；文件元数据记录大小与哈希，下载重现并核对，升级造成不一致时要求再次生成。所有成果默认本人私有；查看和下载审计是只读能力中唯一允许的附带写入。
- 环境变量模型配置优先于既有机构配置。环境密钥不落盘；配置页不允许把它保存回文件，连接测试的验证标记仅保留在内存。
- S0把浏览器、断网与升级演练放入手动完整层，保留快速层及一份汇总构件。首次快速CI暴露规划提交改动冻结用例清单导致哈希不符；恢复为R1验收清单原字节，既有SDK补登记规则不变，没有移除用例或断言。

- GitHub连接器没有dispatch能力，CLI返回Forbidden，网页工具不可用；按守则D2增加显式`[R2-FULL]`代码提交标记作为人工触发后备，仅对`dev/r2-sprint`生效，仍保留workflow_dispatch。普通推送只跑快速层，完整层最多两次。该调整不改变仓库访问权限或验收断言。

- S5不提前引入完整种类注册表或entity_meta侧表；业务卡由已授权的旧载荷、关系、原文引用确定性生成，不调用模型。只读能力复用旧查询与联邦边界，历史快照仅在草稿可见范围展示。
- S6制度单文件通过零必填对话框直接发起配方；多文件和台账保留旧接收器。文件按身份/机构/scope只在内存转交，旧编辑器可先否决跳转，尚未许可时不会上传。
- R1能力库存的三个精确集合、角色契约样本、迁移期望版本随新增能力/0002–0003扩展；不删除用例，不改旧权限预期。R1冻结AST摘要原值保留，另登记edit/_entity_action/_restore_entity三处R2准确摘要（身份元数据保护和事务抽取）。旧首页端到端与单测只增加明确选择保留上传入口及关闭对话框等待，原断言不删减。
- 演示启动沿用Dockerfile的proxy_ca构建secret，读取SSL_CERT_FILE，并在运行容器只读挂载同一证书，未禁用证书校验；代理证书路径不是模型密钥。

- 收尾审查补齐中文数词、百分比、裸数字与混合表格单元格核对；日期/时限逐值一致，金额仍用规范0.5%舍入差。报告标题改取已版本化的引用名称，标题可对照引用元数据，正文只对照原文；不推断业务语义角色。

- 真实复测发现答案会加入来源版本和无原文依据的汇总数量：仅跳过版式序号及与服务端引用精确一致的标识/版本；错误版本、日期与无依据数量仍阻断。演练可在数字门拒绝后发起一次真实模型修订，重新读取来源并再次校验，未修改或绕过数字门。

- 首轮完整CI暴露R1导航精确清单尚未包含新入口；仅增加四个R2链接，旧链接及权限过滤断言保留。旧素材页可用性检查增加从新默认入口点回旧页的步骤，系统信息版本期望随1.1.0更新。本地只复验13条导航/工作台及3条版本路径，全部通过；报告数字拒绝提示补充服务端问题清单，文本转义和显式重试另有单测。
