# R4-A.1 验收用制度材料

三份都是虚构的合成制度，按普通制度的写法准备，不代表任何真实机构。R4-A.1 的动作清单（`../R4-PLAN.md` 第 7 节）与规划方复验都用它们；不得为了通过检查而改写这些文本。

| 文件 | 写法特点 | 用来检验什么 |
|---|---|---|
| `regulation-plain.txt` | 有总的适用范围句；附则写明施行日期；多数条款没有写例外 | 普通制度能否不逐条补同一事实就走到提交 |
| `regulation-repeal.txt` | 同上，但附则为“自发布之日起施行。原办法（自2019年3月1日起施行）同时废止” | 生效日期不得取被废止旧制度的日期，应留空并只问一次 |
| `regulation-history.txt` | 第一条有历史叙述日期；用“本规定适用于”；“自印发之日起施行” | 历史叙述日期不得当作生效日期；“规定”等常见文种的适用范围句能识别 |

规划方 2026-11-18 用真实模型经界面走前两份的结果（修复前），见 `../R4-ACCEPTANCE.md` 第 3 节。
