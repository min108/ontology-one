# R1-5 新外壳与兼容接线

状态：浏览器验收、旧外壳退役与主干全量回归完成。本报告不是 R1 最终验收结论。

## 实现与边界

原 82 个前端文件以 git mv 整体进入 legacy。构建期限定全部旧选择器，包含原 React Flow 样式；旧弹窗和通知进入独立的 legacy-root 门户。旧请求封装未改动，其 SHA-256 为 `677bd70d30a3fefcec350d2fab76d47e339deccc932266257f02b37790315958`。旧页面宽松生成声明，新代码严格读取声明，真实负例验证新消费者仍受 strict 约束。

新外壳提供六个工作区、按权限显示的二级导航、品牌、机构、角色、面包屑、用户菜单与地址状态工具。三种既有角色保留六工作区；两种尚未开放账号创建的新角色只显示工作台、本体、应用。工作区根地址进入第一个已建成且允许的页面。新旧链接保留 query/hash；旧 NavigationProvider 的 via 访问标识与滚动恢复继续保留。

新请求层共用旧 CSRF、工作区标识和业务阻断状态。独立请求代次覆盖收到响应与解析响应体后的检查；401、旧/新 409 均保留原安全行为。Query 键含机构和范围。旧 useAuth 通过 Zustand 提供同样接口；原布尔权限保留，v2 权限键单独保存且校验失败默认拒绝。

机构切换先读取实际编辑、整批上传与浏览器草稿信号。有风险时只确认一次；取消不清缓存、不发切换请求。确认后阻断业务、清理两个请求层、Query、范围、界面及旧浏览器缓存，成功或失败均整页重载。计数是登记信号或暂存键，确认文字不冒称文档数量。具体旧页面保护见 R1-5-GUARDS-REPORT.md。

## 测试和证据

最终主干合入前完整回归：772 个后端用例（733 通过、39 个原有 Windows 原生跳过），16 个流水线测试、8 个回归脚本、前端构建全部通过，11 个检查退出码均为 0。与 R1-1 的 492 项逐条比对，标识和结果完全一致，跳过集合不变。原始日志位于 `work/r1-preflight/r1-5-integrated/`，多行用例名与状态完整归一后再比对。

最终前端单元 207/207 通过；从清空旧声明缓存开始的隔离测试 9/9 通过，含实际 strict 类型错误负例。strict、build、eslint、format、stylelint、Ruff、生成类型/词表、令牌/词表/旧代码边界、策略、迁移与构建产物公网依赖检查全部通过。退役后覆盖 5092 个选择器、30 个旧样式表；入口脚本 gzip 314.29 kB，保留业务页按路由懒加载。受保护依赖文件和两条原生流水线与 0.7.0 字节相同。

浏览器使用真实 0.7.0 结构夹具，隔离建库、迁移、启动实际双服务；原 75 条旧页面用例保持不变。新增导航、重定向、两种视口和取消/确认切换协议；本地系统 Chromium 只作诊断，规范版本在 CI 下载运行。1093×614 是 1366×768 在 125% 下的等效 CSS 视口，不能冒称实际浏览器缩放。

## 好用性与文案自查

外壳只承担导航与查找，未增加业务必填项；确认仅在确有待丢弃编辑或上传时出现。搜索支持键盘、空结果、加载和失败重试；没有权限的工作区根提供返回入口。长任务仍通过真实旧后台任务与智能对话承接。角色名、导航、确认文案均从统一词表生成；技术标识没有改名。简洁/专业视图开关已接界面状态，服务端持久偏好在 R1-7 完成，不伪造尚未存在的接口。

## 集成复核修复

- 保留站内待办与品牌的 SPA 导航，避免整页刷新丢失原来路/滚动缓存；品牌根导航使用显式标记。地址工具合并同一事件中的连续更新，保留其他筛选和锚点。
- 会话操作使用专用 AbortController；新的 reload/accept/login/logout 取消旧身份请求，旧 401/409 与延后 JSON 解析不再触发全局失效，当前错误仍正常处理，不取消无关业务请求。新增 46 项竞争测试。
- 集成应用的非管理员直达继续呈现原无权限页面和原服务端保护，导航仍不显示入口；机构选择不使用虚拟选项，现有完整目录可被键盘与辅助技术读取。
- 两个图谱视图的迟到动画回调须在组件卸载、工作区离开及导航过渡期间停止写地址；回归和真实浏览器共同核验，不能通过等待动画规避。
- 清理 8 页口号/装饰时，1316 动态 JSX 表达式与 52 链接目标逐项保持；随后仅将 10 个旧管理链接指向新路径。分别见 R1-5-LEGACY-COPY、R1-5-LEGACY-LINKS。
