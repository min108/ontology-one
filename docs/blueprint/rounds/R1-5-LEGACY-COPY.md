## 核验

用 TypeScript AST 对比修改前后八个页面：全部 1316 个非字面量 JSX 表达式及 52 个链接目标逐项相等，确认事件处理、数据条件、统计值和操作目标没有被删改；八页 JSX 解析均无错误。`git diff --check` 通过。此次为展示文本/装饰删除，不新增仅复述实现的测试；后续统一外壳构建及旧页面冒烟由 root 完成。

删除后 hero/banner/slogan 检索在本批非 Overview 页面只剩 AssetDetail 身份/历史横幅与 Graph 历史提示，均已在上表逐项保留说明。遗留未使用 CSS 暂不整理，避免扩大本包范围。
