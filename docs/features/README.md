# 知元功能全景

`知元功能全景.docx` 列出知元的全部功能点（605 个）：已经做出来的、蓝图里规划了还没做的、以及应该有但还没设计清楚的。供负责人逐条批注、决定增删调整，再交回规划方据此调整计划。

## 怎么批注

- 在每张表最右边的“您的意见”列里直接写，例如“不要”“提前到第 2 轮”“改成……”；
- 或者用 Word 的“审阅 › 新建批注”；
- 想直接改文字时，先打开“审阅 › 修订”，规划方能看到改了哪里；
- 要新增功能，写在对应模块表格末尾标着“新增”的空行里。

改完把文件交回规划方（在对话里上传，或替换本分支里的这个文件）。

## 文件说明

| 文件 | 用途 |
|---|---|
| `知元功能全景.docx` | 给负责人看和批注的文档 |
| `features.json` | 全部功能点的原始数据（编号、名称、说明、状态、何时做、依据出处） |
| `build_docx.js` | 由数据生成 Word：`node build_docx.js features.json 知元功能全景.docx <日期>`（需要 npm 包 `docx`） |
